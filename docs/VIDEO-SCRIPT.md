# Сценарий демонстрационного видео

Целевая длительность: 3–4 минуты. Записывать экран в разрешении 1920×1080.

| Время | Экран | Текст ведущего |
|---:|---|---|
| 0:00–0:20 | Первый слайд презентации | Представить проблему и Repo Health Score. |
| 0:20–0:50 | `/ranking` | Показать фильтр языка и сортировки по Score, likes и активности. |
| 0:50–1:35 | Dashboard `divkit/divkit` | Показать целый Score, Data Coverage и раскрыть две категории с evidence. |
| 1:35–2:05 | Рекомендации | Открыть приоритет, проблему, действие и ожидаемый прирост Score. |
| 2:05–2:35 | «Мои репозитории» | Войти через Я ID, выбрать репозиторий и запустить повторный анализ. |
| 2:35–2:55 | Страница анализа | Показать статусы QUEUED, COLLECTING, CALCULATING и COMPLETED. |
| 2:55–3:15 | История Score | Показать новую точку и объяснить регулярный пересчёт. |
| 3:15–3:35 | Скачать отчёт | Скачать PDF или Markdown и открыть первые разделы. |
| 3:35–3:55 | Слайд архитектуры | Завершить очередью, обработкой 10 500 файлов и честным AppSec fallback. |

Перед записью очистить уведомления, закрыть личные вкладки и убедиться, что в
кадр не попадают `.env`, токены, cookies или консоль с секретами.
