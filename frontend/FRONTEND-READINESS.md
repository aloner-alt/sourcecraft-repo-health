# Готовность frontend

## Подключено к backend

- Рейтинг загружает до 100 реальных репозиториев и поддерживает поиск,
  язык, сортировки и локальную пагинацию.
- Dashboard показывает настоящий Score, Potential Score, Data Coverage,
  шесть категорий, статусы источников, метрики и рекомендации.
- `NO_DATA` и `PERMISSION_DENIED` отображаются как отсутствие данных, а не как
  нулевая оценка.
- Страница анализа автоматически опрашивает backend и показывает этапы, ошибку или итоговые значения.
- Markdown и PDF скачиваются из backend.
- Я ID, профиль, персональная рабочая область, импорт публичного репозитория и повторный анализ подключены к backend.
- Главная страница и рабочая область используют реальные данные.
- Next.js production build проходит на Node 22, а весь стек запускается через
  Docker Compose на портах 3000 и 3001.
