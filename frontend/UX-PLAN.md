# UX-план

- [x] 1. Вход через Я ID и место для аккаунта (без имитации сессии).
- [x] 2. Настройки темы и анимаций, сохранение предпочтений.
- [x] 3. Действия Dashboard рядом с названием, без ложных ссылок на источники.
- [x] 4. Появление чисел, заполнение круга и полосок.
- [x] 5. Плавные взаимодействия, независимые колонки.
- [x] 6. Проверка обеих тем, телефона, клавиатуры, reduced motion и сборки.

Реальные OAuth, источник репозитория и результат анализа требуют backend.

Проверено: светлый Dashboard на широком экране, тёмные настройки и Dashboard на 390 px, сохранение предпочтений после перезагрузки, отсутствие горизонтального переполнения, раскрытие Enter без растяжения соседней карточки, отключённая CSS-анимация, отсутствие ошибок консоли. Системный reduced motion учтён в CSS и JS, отдельно настройка ОС не переключалась. ESLint и Next production build (включая TypeScript) прошли.
